# POSTING_RULES — правила выкладки комплекта

Перед публикацией куда-либо (GitHub, Telegram-канал, блог, маркетплейс) —
проверь по чек-листу. Каждый пункт — обязательный.

## 1. Секреты и ключи

- В репозитории НЕ должно быть ни одного реального ключа/токена/пароля:
  API-ключи, proxy-логины, cookie-сессии.
- Все ключи — только плейсхолдеры вида `YOUR_API_KEY`, `YOUR_TOKEN`.
- Проверка перед выкладкой:

```bash
grep -rniE 'api[_-]?key|secret|token|password|passwd' --include='*.py' --include='*.json' --include='*.env' .
```

- Файлы `.env` и `*.example.env` — только примеры, без реальных значений.
- Если в истории git были секреты — история переписывается (filter-repo),
  а не просто удаляется файл.

## 2. Служебные пути

- В коде НЕ должно быть абсолютных путей к чужим машинам:
  `/home/*`, `/run/media/*`, `C:\Users\*`.
- Все пути — относительные или через переменные окружения.
- Кэш/данные — только `~/.cache/...` или `$XDG_CACHE_HOME`.
- Упоминания чужого воркспейса (`AGGG2.0`, имена проектов, venv `~/.venvs/aggg2`)
  — заменены на нейтральные или параметризованы.

## 3. Атрибуция и лицензия

- Указано авторство и источник: канал t.me/aidvizhenie · админ @hilartem ·
  хаб t.me/aidvizh_hub.
- Если комплект собран на основе чужих работ (camoufox, mcp, trafilatura) —
  их лицензии и копирайты сохранены в файлах/README.
- Если публикуешь под своей маркой — не удаляй исходные копирайты
  зависимостей (это нарушение их лицензий).

## 4. Качество

- `python3 -m py_compile` — все .py компилируются без ошибок.
- README корректен: пути установки, команды, примеры конфигов —
  проверены на свежем окружении (не по памяти).
- Демо-скриншоты/примеры в `research/` — без персональных данных
  и без содержимого закрытых систем.

## 5. Безопасность комплекта

- Скачанное пользователями выполняется у них на машине: код должен быть
  честным и предсказуемым, без скрытых сетевых вызовов, без телеметрии.
- Загрузка страниц — только по запросу пользователя.
- Уязвимости (SSRF-риски при fetch произвольных URL) описаны в README
  с объяснением, а не спрятаны.

## 6. Чек-лист перед коммитом

- [ ] `grep` по секретам (п.1) — чисто
- [ ] нет cookies / session state / storage_state*.json / proxy credentials
- [ ] нет `*.sqlite`, `*.db`, `*.log`, `.env` в дереве (только в .gitignore-паттернах)
- [ ] абсолютных путей нет (п.2)
- [ ] `py_compile` проходит
- [ ] `pip install .` проходит с нуля (чистый venv) и entry point `camoufox-research` запускается
- [ ] MCP stdio smoke: initialize → tools/list → ping (CI делает это сам)
- [ ] README соответствует текущему коду (проверен с нуля, не по памяти)
- [ ] копирайты зависимостей на месте (camoufox/mcp/trafilatura)
- [ ] в `research/` нет личного
- [ ] Windows и Linux: пути bin/ vs Scripts/ корректны (`_compat.py`)

И только после этого: `git init → commit → push`.
