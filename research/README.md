# research/ — публичное окно (Pages), добыча живёт в кэше

**С 28.08 приватные отчёты кампаний пишутся в кэш**:
`~/.cache/camoufox-research/research/` (каталог от watchdog-лога,
см. `_report_dir()`). Папка в репо НЕ дублирует добычу.

В репо осталось только:
- `public/` — отчёты, **разрешённые к публикации** на GitHub Pages
  (витрина aidvizhhub.github.io/camoufox-research). Класть сюда вручную
  из кэша, когда хочешь показать племени.
- этот README.

Скриншоты/заметки — тоже в кэш (`~/.cache/camoufox-research/`),
в репо им не место.

## Что где лежит

- **`YYYY-MM-DD-тема.md`** — автоотчёты кампаний (пишутся автоматически
  при завершении; см. `CAMOUFOX_REPORT_DIR` в configs/example.env).
  **Приватные** — в git НЕ идут (research/*.md в .gitignore).
- **`public/`** — отчёты, **разрешённые к публикации** на GitHub Pages
  (витрина aidvizhhub.github.io/camoufox-research). Класть сюда вручную:
  `cp research/YYYY-MM-DD-*.md research/public/` — и только чистые
  (без секретов/личных путей; скан: grep -iE "key|token|…").
- **`INDEX.md`** — оглавление всех отчётов (автособирается при
  сохранении; пересборка вручную: `python scripts/reports_index.py`).
- **`cit/`** — цитатные пакеты кампаний (`cmp_*.cit.md`, выжимки для
  синтеза с нумерацией [1..N]) — вторичный материал к отчётам.

## Места хранения (не путать)

| Что | Где | Судьба |
|---|---|---|
| Отчёты (md) + INDEX + cit | `research/` | вечный архив (метла НЕ трогает) |
| Артефакты кампаний (cmp_*.log/json) | `~/.cache/.../exports` | TTL-чистка 30-90 дней |
| Кэш страниц/поиска | `~/.cache/.../cache.db` | TTL 24ч-30дней |
