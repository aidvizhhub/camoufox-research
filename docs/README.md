# docs/ — витрина и грабли

Здесь живут примеры и накопленный опыт проекта (кто как делал, на что
не наступать). Рабочие отчёты кампаний — в `research/` (см. README там).

## Витрина добычи

- [`example-report.md`](example-report.md) — пример автоархива кампании
  (feeds-only, без поисковика): таблица источников с классами качества
  (первоисточник / надёжный / форум-блог) — как выглядит «сырая» добыча.
- `research/INDEX.md` — живое оглавление всех отчётов (автосборка при
  сохранении; пересборка вручную: `python scripts/reports_index.py`).

## Грабли (проверено, не наступать)

- [`landmines.md`](landmines.md) — 20+ граблей проекта с прод-фиксами.
- [`batches.md`](batches.md) — летопись батчей 1-17 (кэш, экономия).
- [`batches_early.md`](batches_early.md), [`batches_late.md`](batches_late.md)
  — детали ранних и поздних батчей.
- [`bench_auto_workers.md`](bench_auto_workers.md) — бенчмарк авто-воркеров
  (сколько браузеров тянет машина; per-host cap).

## Отчёты vs документы

- Отчёт кампании (добыча) → `research/` (архив, вечный, INDEX.md).
- Документация/грабли → `docs/` (этот каталог).
- Кэш-артефакты (`.cit.md`, дубли) → `~/.cache/.../exports` (TTL-чистка).
